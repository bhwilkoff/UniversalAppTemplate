Leader's guide

A cohort

Length
Five weeks, after a prep week
Meets
Weekly on Google Meet, about 75 minutes
Groups
Three learners, kept together
Calls hosted by
meet@humanshaped.org
Leaders
One or more per cohort

Before the first session

  1. Co-lead one session firstAnother cohort's leader adds you under People
  2. Set the day and timeSettings
  3. Make the weekly sessionsSessions
  4. Ask for Meet linksOverview. meet@humanshaped.org makes the weekly call, so no personal account is needed.
  5. Make the GitHub repositoryOverview. It holds the cohort's conversation.
  6. Open for joiningSettings
  7. Make the groupsGroups, once people have joined. Ask for Meet links again for their rooms.
  8. Rehearse on the live sessionLive session
  9. Connect your agent (optional)Connect

Each session

Run it from
The Human Shaped add-on in Meet, or the live session beside Meet
Main stage
Present it from the add-on to show the welcome or a card

The add-on is still in testing. Until it is listed, keep the live session open beside Meet.

The six parts

  1. ArriveOne line each in the chat, then what you read in last week's checks
  2. Show what you brought backIn groups, about eight minutes each
  3. One value at workBack together, one decision shared
  4. Read one real prompt togetherEveryone tries it first
  5. StartThe coming week's first prompt, written before leaving
  6. Check for understandingThe last three minutes

Between sessions

  • Read the checks and say what changesFollow-up. Learners see it as they arrive next session.
  • Answer feedback and questionsFeedback, oldest first
  • Write each learner a follow-upFollow-up
  • Write to anyone who missed the sessionFollow-up, within two days
  • Change next week's run of showSessions

When the cohort finishes

  • Mark the cohort finishedSettings
  • Record each credential that was earnedCredentials. A signer then signs it.

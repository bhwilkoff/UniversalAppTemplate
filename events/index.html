If you are hosting a gathering about this work, tell us about it on GitHub, and it will be listed here once someone has read it, usually within a few days. Everything you write there is public, so leave out anything you would not put on a flyer. When it is over, start a discussion about what the room learned and add its link, so the next person who hosts one can start from it.

The guides for a meetup and a hackathon have everything else you need, from the first words to the sheets to print.

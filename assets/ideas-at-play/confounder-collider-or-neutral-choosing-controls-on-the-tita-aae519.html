Confounder, collider or neutral?

Assumes you have read Ch. 5 of Cunningham's Causal Inference: The Remix (§5.2). Work through the numbered steps in order. About 25 minutes.

Haven't read it? Here's what you need

A DAG draws causes as arrows. To get the effect of D on Y, only the causal path D → Y should stay open. A backdoor path starts with an arrow into D, like D ← W → Y. Controlling for W, a confounder, closes it.

A collider is a variable two arrows point into, like D → F ← Y. Leave it out: controlling for it opens a false link. A variable that only affects Y is neutral. It fixes no bias but can make estimates more precise.

§5.2's emergency rules for when you have no DAG:

  1. Include variables you are confident are confounders.
  2. Include strong predictors of the outcome measured before treatment.
  3. Leave out anything treatment might have caused, and at least everything measured after it.

Assumptions behind the numbers
  • Parameter. Each voyage has 2,201 simulated passengers, and a voyage set has 200 voyages. First class raises every passenger's survival probability by exactly 15 points.
  • Distribution. Each passenger is a man (69%), a woman (21%, W = 1) or a child (10%, C = 1). A thermal swimsuit (S) goes to 40%, independently of everything else.
  • Distribution. P(D = 1) = 0.11 + 0.25·W − 0.09·C. P(Y = 1) = 0.05 + 0.15·D + 0.30·W + 0.30·C + 0.50·S, which peaks at exactly 1. P(F = 1) = 0.03 + 0.30·D + 0.30·Y.
  • Simplification. Survival is built linear and additive, and every probability stays within 0 to 1, so OLS of Y on D, W and C is correctly specified. Real survival had many more causes.
  • Interpretation. Large-sample values: no controls +21.9 pp; W alone +13.0; W and C +15.0 (SD 2.97); W, C and S +15.0 (SD 2.56); W, C and F −1.2; all four +3.0.
  • Data. Step 6 is a stylised version of the NSW job-training comparison with survey controls (LaLonde). No data are simulated for it.

Left out: M-bias, where a pre-treatment variable is itself a collider (the book's footnote 4); choosing covariates by regressing pre-treatment outcomes on candidates; Cinelli, Forney and Pearl's (2022) catalogue of good and bad controls; and automated covariate selection, which can be biased unless colliders are removed first (Hünermund, Louw and Caspi 2023).

Precedence and the conditional (IF–THEN)

5Precedence predict first

Precedence is the order in which R applies the operators in an expression when there are no parentheses to say. Parentheses override it: whatever is inside them is worked out first.

Before you run anything: with P <- TRUE and Q <- FALSE, what do you expect !P | Q to be? What about !(P | Q)? Write both predictions down, then run the cell.

Both FALSE? That’s a coincidence of these values, and it hides the point.

6Conditional (IF–THEN)

Did you put Q back to FALSE? Cell 5 set Q <- TRUE. Run cell 1 again before going on, or the answers from here on will differ from your classmates’.

R gives you AND (&), OR (|) and NOT (!), but there is no operator for the conditional, the IF–THEN sentence (→). Build it. Recall when P → Q is false, and write an expression using only the connectives you have.

Watch out: P <= Q appears to work, because R turns TRUE and FALSE into 1 and 0. That’s arithmetic, not logic, and it will mislead anyone who adopts it. Use only &, | and !.

How I built it.

On November 4, 2026, I opened up my first session with this add-on approved and installed, and none of the folks in my cohort could see the main stage. Everything I have built since then started with that hour.

What I wanted.

People understand a video conference, but almost no one has been in a learning session that happens inside of one. I wanted my learners to be able to answer a question, show one another what they have made, and ask for help without ever leaving the call. And I wanted to be able to lead all of it without having two other pages open.

I build with an agent. I decide what we are making and why, I use it with real people, and I say so when it doesn't make sense. The agent writes the code. That sounds tidy, but it wasn't, because a thing can look finished in a browser and still not work at all inside of a call. So, I made one rule: nothing is finished until we have seen it work in a real Google Meet™ call, with a leader and a learner in it.

That rule has taught us a great many things that we couldn't find written down anywhere. Meet won't draw a PDF on the main stage. The panel and the stage can't see what the other one has saved. And the add-on can't use your microphone, although a window that it opens can. All of those lessons are now in the template, which means that the next person won't have to learn them the way that we did.

Bringing in a Course Builder course.

I already had a course inside of Minerva's Course Builder, and I wanted to know if I could run it in Meet without building it all over again. So, we figured out how to bring it over. You export the course, paste the link into Bring in a course (please don't open it first, because it only works once), and every session shows up as a draft that you can revise. Nothing about the people in the course comes with it.

If you have taught in Forum, you will recognize what happens next. Polls become questions on the main stage, and a repoll sits beside the first set of answers so that you can see what changed. You can still feature someone who has been quiet, and it will tell you why it chose them. Breakout groups get their own Meet rooms, and they fill in their workbooks together.

And yet, the first time I tried to run one of those sessions, a huge number of the resources were too big for the window or didn't load at all. We turned the PDFs into slides. We blurred a workbook that had real applicants in it. We went back and found the names for the learning outcomes, which had come over as nothing but numbers. I only knew about any of that because I tried to teach with it.

Try it in a call of your own.

You don't need an account for this. Add Human Shaped from the Google Workspace Marketplace™, start a Meet call, and open it up from Activities. You will have slides with your own notes, questions, a way to vote on ideas, and a main stage where everyone in the call can try out the same website. It takes about five minutes to get started, and you can read about everything it does first if you would rather.

Build something of your own.

Everything that I know about building this way is in the Universal App Template. You make a copy of it, and your agent reads what we have learned before it builds anything for you. If you are interested in making something for a live class, start with what we know about Meet add-ons, what we know about live sessions, and how we run all of it for free. The code for the add-on is there too.

If you would rather learn to build with other people, our cohorts are free. What you make is yours, and I would love to see it.

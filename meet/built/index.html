How it was built.

Human Shaped's add-on for Google Meet™ was built by one educator working with a coding agent and a template repository of skills, and everything it learned along the way is in that template, free, for anyone who wants to build tools for learning the same way.

Try it in a call of your own.

Add Human Shaped from the Google Workspace Marketplace™, start a Meet call, and open it from Activities. In a call that is not a cohort's, you need no account at all: Start a session gives you slides with your own notes, questions counted without names, a vote on ideas, stances, a clock, and a website on the main stage where everyone in the call gets their own working copy. Trying it takes five minutes, and everything it does is on its own page.

A Course Builder course, running in Meet.

A leader makes an export in Course Builder and pastes its link into Bring in a course without opening it, because the link works only once. Human Shaped hands Course Builder its own address and waits for the course to arrive, and it becomes a draft cohort with every session and every part in order. Nothing about people comes with it.

Each Forum step has a place in the call. A poll is a question on the main stage, a repoll asks it again beside the first, poll results become a debrief that pins the answers, and Feature User keeps its Quiet, Random, and Voting choices, with Quiet counted from what was actually recorded in that call. Breakouts open as Meet rooms sized the way the step says, and each room fills in its own copy of the workbook together.

Running the imported course in real calls changed three things: Meet's frames cannot draw a PDF, so each one became picture slides; a workbook that held real applicants' documents was blurred; and the learning outcomes, which arrive as numbers, take their names from Course Builder's outcomes file.

One educator, one agent, a template.

Since October 1, 2026, the site and the add-on have taken more than a thousand commits and nearly a hundred database changes, written with a coding agent. The educator decided what to build and why, used it, and judged it; the agent wrote the code and ran the checks. The habit that mattered most was simple to say and hard to keep: no feature counted as done until it worked in a real Meet call, with a leader and a learner in it.

That habit is how we learned the things no documentation said. Meet's main stage cannot draw a PDF. The panel and the stage share no storage, so two browser tabs can never prove that something passes from one to the other. The add-on's own frame is refused the microphone and the screen, while a window it opens is not. Each of these is now a rule in the template, so the next tool built from it starts out knowing.

It all runs at no cost, on free tiers of GitHub Pages, Supabase, and Cloudflare Workers, which also means every job has to be built to use very little, and a run that repeats the same failing work is treated as a bug rather than a schedule.

Take the method with you.

The template is a repository you copy to start your own app, with skills your agent reads before it builds. The ones behind this add-on are google-meet-addon, live-learning-sessions, and zero-cost-hosted-backend, and the add-on's own code and design notes are on the template's site branch.

If you would rather learn to build this way with other people, our cohorts are free, and what you build is yours.
